# Ethera — Visual and Interaction Design

**Author:** Babuni.dev  
**Authority:** This guide indexes existing canonical specifications. It does not replace them or approve new visual decisions.

## Intended experience

The [game vision](../concept/Morkahja-Live-RPG/00_Core/Game_Vision_and_Principles.md) describes a quiet, curious, dreamlike shared world. Players temporarily inhabit people who already have histories, relationships, abilities, possessions, and unfinished work. Actions and knowledge persist with those people and their community. Game information should emerge through movement, sound, material changes and contextual interfaces rather than conventional explanatory screens alone.

## First playable: Khar-Morr

The [first-playable scope](../concept/Morkahja-Live-RPG/99_Development/First_Playable_Scope.md) centers on Khar-Morr shaping a club from rock, swapping equipment and sharing an event Shard with the Memory Fountain. Its authored stage is a small Grimnir village-center area with a separate Fountain, stone resources and a container. Shape Trace and Shard Fit are skill interactions; the character panel and development log reveal their consequences. The first milestone's simulation exists in source, while the [game README](../game/README.md) explicitly identifies current 3D presentation as placeholder-based.

## Need and Divine Orientation

The [Milestone 3 specification](../concept/Morkahja-Live-RPG/99_Development/Milestone_3_Need_and_Divine_Orientation.md) defines the **Stone Weapon** Need, **Acquire a Stone Weapon** Common Task, character-specific reserved objective, dynamic checklist that hides unknown knowledge, and intermittent **Ground Wind-Wave / Ground Glint** signs. The task completes because the character acquires a qualifying item, not because a specific scripted path was followed. These are canonical design requirements, **not evidence Milestone 3 is implemented**.

## Implementation and verification

Godot 4.7.2 hosts a desktop scene, using placeholder meshes where finished authored models/presentation are incomplete. The repository contains art source and Godot assets; individual visuals should be inventoried with provenance before portfolio publication. See [game presentation documentation](../game/docs/PRESENTATION_AND_ASSETS.md), [canonical concept index](../concept/Morkahja-Live-RPG/README.md) and [content guide](CONTENT.md).
