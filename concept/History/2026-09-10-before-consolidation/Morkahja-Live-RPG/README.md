# Morkahja Live RPG

A persistent multiplayer RPG about temporarily inhabiting people who already belong to a living elemental world. Characters, community, knowledge, and history endure beyond any one player's session.

## About this archive

This folder contains the game concept consolidated into the requested structure, extended with focused topic pages: **64 Markdown files across nine topic folders**, including this README. It draws on the complete retrieved **Morkahja live RPG** design conversation and the supplied world-and-peoples PDF. Later user corrections take precedence over earlier brainstorms.

The established concept is written directly as design documentation. Tentative details and unresolved implementation choices are marked where relevant. The initial PDF-only proposals have been replaced. Updated through 2026-09-10, through answer 104, including the subsequent 45 design turns and their corrections.

## Source preservation

The complete retrieved design conversation is saved beside this folder as [Morkahja-Concept-Sources.md](../Morkahja-Concept-Sources.md), retaining user and assistant speaker labels. The ZIP includes both this folder and that transcript. The structured documents are the readable concept; the transcript preserves detail and provenance.

Sources: [Morkahja live RPG](https://chatgpt.com/c/6aa08555-1c60-83eb-ae68-d3555edd8d7f), [Create Morkahja Files](https://chatgpt.com/c/6aa14c6a-beec-83eb-865f-0e20d93e24a2), and the supplied *Morkahja - World and Peoples.pdf*. Synced files were left unchanged. This is a local snapshot, not automatic ongoing synchronization with project conversations.

The broader lore's developed cities and cultural institutions are preserved as reference, while the RPG takes place in an earlier age. Precise ancient-era adaptations remain open rather than silently rewriting either source.

## Added on 2026-09-10

Desires and Needs, baseline actions, injuries, combat, trade and exchange, the paired interaction system, and persistent world nodes now have dedicated pages. Existing knowledge, social, world, and interface pages are updated to match. See [Changelog](99_Development/Changelog.md) for the update record.

## Second update on 2026-09-10

The current concept includes playable youth and the adulthood rite, converging destiny, recoverable failure, the first Grimnir settlement, physical equipment, deterministic crafting, discovered interaction records, simulation-generated community tasks, and subtle Divine Orientation. The latest open question is whether guidance operates on broad destiny without an active task.
