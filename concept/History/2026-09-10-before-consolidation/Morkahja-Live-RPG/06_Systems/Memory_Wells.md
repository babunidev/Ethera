# Memory Wells

**Status:** Established concept, updated 2026-09-10. Later user decisions supersede earlier brainstorms; unresolved details are marked.

## Practical cultural knowledge hubs

Memory wells name the collective knowledge function. Each culture expresses it through its own hub and customary interaction or ritual. These need not be identical physical wells.

Characters contribute knowledge to the archive and consult it to update information relevant to their current Needs. Broad library browsing and historical research UI are not a priority for this version.

## Layered knowledge

Collective memory retains outdated shards beside newer ones. Current objective support chooses the newest relevant known shard, while old records remain as history. Individual characters instead replace obsolete personal information when a newer relevant shard is actually received.

## Routing an objective

A character last heard of a bear at a cave. During a later consultation, the hub can follow its recorded knowledge: the bear was killed, someone took the claw, and a person now possesses it. It provides the relevant shard so the Need points toward that person.

This lookup is automatic within the cultural consultation. It is not omniscience: unobserved or unshared events do not become globally available merely because they happened.

## Simplicity

No memory capacity or burden system is required. Contributing knowledge is not a mandatory offloading minigame. Personal clearing on contribution has not been independently specified beyond the copying simplification recorded in [Knowledge Shards](Knowledge_Shards.md).

The hub grants or copies relevant knowledge through a direct cultural interaction. A separate task action accepts suitable community work and begins guidance; no task-choice menu is required. See [Environmental Guidance](../07_Presentation/Environmental_Guidance.md).


## Simulation-generated community tasks

The fountain checks the settlement's needs and the character's suitability. It provides an appropriate task, or generates useful preparation if no urgent work fits. Interaction performs acceptance directly. Divine Orientation can then lead toward current reality independently of stale personal knowledge. See [Community Tasks](../04_Community/Community_Tasks.md).
