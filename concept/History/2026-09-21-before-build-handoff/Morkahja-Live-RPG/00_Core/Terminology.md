# Terminology

## People and lives

| Term | Meaning |
| --- | --- |
| Morkahja | The shared elemental world. |
| Inhabitation | Temporary player control of an existing person. |
| Trait | A binary quality describing identity, ability, appearance or preference. |
| Preference Trait | An enduring attraction such as Likes Kind, matching a corresponding quality. |
| Birth Traits | Twenty-seven latent personal Traits: nine from each creator and nine from the personal pool. |
| Role | A cultural title expressing dominant Traits, first revealed at adulthood and updated at the fountain. |
| Creator | One of the two contributors to a Grimnir's inherited identity. |
| Playable youth | The supported developmental stage where a player can begin inhabiting the person. |
| Adulthood rite | The culmination of youth participation that begins adulthood and Destiny. |
| Essence | The sustaining coherence of individuality, mind and motivation. |
| State | A temporary condition affecting current actions or properties. |
| Outing use | One departure-and-return cycle supported by a temporary effect. |
| Stand-in | An opted-in queued player temporarily continuing a disconnected person's session. |

## Knowledge, tasks and progression

| Term | Meaning |
| --- | --- |
| Need | An owned current requirement with one or more valid fulfillment paths. |
| Task | A set of requirements pursued as an undertaking. |
| Specific Need | A requirement bound to a particular entity or object. |
| Generic Need | A requirement that accepts matching valid solutions. |
| Important Need | An authored Need highlighted for the player's attention. |
| Shard / event Shard | An immutable factual record of a resolved action/reaction round or discovery event, known through its stable ID. |
| Shard-holder | An entity with references to known Shard IDs. |
| Shard reference | Access to one existing event record shared among holders. |
| Authored permanent Shard | A record the Memory Fountain retains indefinitely once learned. |
| Ordinary retention | One week of world time from the Shard’s original creation. |
| Interaction history | A separate lightweight record of the character’s latest 100 interactions. |
| Solution Shard | Information connecting a Need to a solution or source. |
| Collective memory | Contributed knowledge retained through the Fountain and deliberately preserved archives. |
| Memory Fountain / Knowledge Fountain | The cultural consultation function for knowledge and task support. |
| Recall Knowledge | Contextual inspection of known facts about a person and knowledge taught or received. |
| Shared event | A factual interaction record that can support later actions while its relevant knowledge remains available. |
| Recognition / Sympathy / Trust | Permanent relationship steps enabled by one, two and three matching pairs and performed interactions. |
| Divine Orientation | Intermittent environmental signs supporting the current useful route. |
| Priority stone | The marker selecting an existing task or unlocked Destiny quest. |
| Destiny Crest | A branching undertaking with Combat, Trickery, Aid and Social approaches. |
| Destiny Knot | The culmination of a Crest, followed by another Crest. |
| Reproduction Destiny | The creators' special progression supporting a new life. |
| Atranor | The place of divine judgment where a life can be renewed or dissolved. |
| Dissolution | The final end of an individual's existence. |

## World, items and interactions

| Term | Meaning |
| --- | --- |
| Terrain tile | A large hexagonal section of landscape containing many local places. |
| World node | A persistent local place with current properties and content. |
| Content slot | A place for an occupant, item or other replaceable content within a node. |
| Body slot | A meaningful carrying or equipment position. |
| Okay / Broken | The two equipment-condition states. |
| Interaction | An authored action with requirements, target, skill phase and results. |
| Requirement group | Conditions combined with AND; complete alternative groups combine with OR. |
| Skill phase | The player's performed challenge within an interaction. |
| Body-part injury | Binary Injured/uninjured condition restricting dependent actions. |
| Aimed Attacks | Trait enabling deliberate attacking body-part selection before the player-skill phase. |
| Reaction phase | The response opportunity following a successfully executed primary action. |
| Resolved round | One primary action, its reactions and its final result, recorded in one event Shard. |
| Attack reading | Learned capability to recognize the body region targeted by an opponent. |
| Shared entity framework | The common technical representation of people, creatures, objects and places. |
| Interaction change flags | Internal category changes used to refresh cached action availability. |
| RealmNode | The distributed runtime foundation developed alongside the game. |

| Shape Weapon | Combat / Weapon Craft action shaping a suitable world rock into an equipped club. |
| Weapon Shaping | Actor capability Trait required for Shape Weapon. |
| Rock | Material identity Trait on the shaping target. |
| Shapeable | Target capability Trait marking material suitable for shaping. |
| Weapon / Stone Weapon | Traits of the created stone club. |
| Small Weapon | First equipment slot, visibly attached to Khar-Morr's back. |

| Shard Fit | Knowledge phase: position an automatically rotating symbol and click when it matches its recess. |
| Echo | Target capability Trait required by Echo Imprint and Echo Attunement. |
| Echo Imprint | Automatically contribute one known Shard the target lacks, sharing the existing reference. |
| Echo Imprint Trait | Working actor-capability name for Echo Imprint. |
| Blocker | An active negative state's restriction on an interaction or Trait, evaluated after normal requirements. |
| Inherent action | Basic direct action such as walking or item pickup. |
| Discovery | Hover-triggered observation action recorded in the common Shard format. |
| Discovered | Factual result of a Discovery event. |
| Development event log | Temporary in-game list of action and state changes supporting prototype inspection. |
