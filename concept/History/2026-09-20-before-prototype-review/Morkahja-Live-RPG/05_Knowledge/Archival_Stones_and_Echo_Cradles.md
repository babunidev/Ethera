# Archival Stones and Echo Cradles

An archival stone is a craftable physical object with three Shard slots. It preserves chosen knowledge indefinitely, allowing discoveries and memories to survive the person who knew them. Ordinary memory stones follow the normal one-week retention rule.

## Making and using a stone

Archival stones use the normal crafting system, with the appropriate capability, materials, tools and place. Using one requires either the relevant Trait or the relevant knowledge Shard. The character chooses from knowledge they currently hold.

The same Shard can be preserved in several different stones. Each holds a reference to the same record, and the character continues to know it within their own retention rules. Each archival stone accepts three Shards. When its slots are filled, further Shard Binding requires another stone.

## Echo Cradle

An Echo Cradle is a permanent, reusable world object providing the physical base for Shard Binding and Absorb Knowledge. A character can shape a suitable base with the required Trait or knowledge and material.

The player hovers the Cradle, holds left click and chooses an available interaction. A carried stone is selected and visibly sockets into the base for the action. On completion it returns to inventory. Insertion and removal belong to that single interaction; the Cradle provides its physical setting.

## Shard Binding

Shard Binding preserves one currently known Shard in a selected archival stone:

**Focus Echo Cradle → choose Shard Binding → select carried stone → stone sockets → choose known Shard → binding completes → stone returns to inventory.**

The knowledge-selection list places authored permanent Shards first, followed by other currently known Shards. The player chooses what to preserve. Expired knowledge is absent from the character's list. A successful round creates one event Shard recording which knowledge was bound into which stone.

## Absorb Knowledge

Absorb Knowledge uses the same Cradle and temporary socketing sequence. It gives the character references to every Shard in the selected stone that they do not already know. The stone retains its contents and returns to inventory afterward.

The event Shard records only the knowledge actually learned. If a stone contains three Shards and the character already knows two, the result references the one newly learned Shard. Learning preserves each record's identity and original creation time.

## Memory Binding

Memory Binding joins a carried memory or archival stone to the Memory Fountain. The Fountain is the world target. After choosing the interaction, the player selects a non-empty carried stone from a list; hovering a stone shows its stored Shards. A clear warning explains that the whole stone will be consumed.

On successful resolution, the Fountain receives every Shard reference from the selected stone before the physical stone is removed. The event Shard records the stone and knowledge transfer. The Fountain applies its own retention policy using each record's original creation time: authored permanent records persist, and ordinary records follow their one-week lifetime.

Memory and archival stones are indestructible through ordinary world activity. Memory Binding is the dedicated way to consume them, preserving the transfer before removing the object.

## Knowledge left behind

A traveler binds a discovery into a stone, keeps knowing it and leaves the stone for others. Their later death removes their personal references, while the stone continues to preserve the discovery. Another capable person can learn it through Absorb Knowledge, or carry the stone to the Fountain for Memory Binding.
