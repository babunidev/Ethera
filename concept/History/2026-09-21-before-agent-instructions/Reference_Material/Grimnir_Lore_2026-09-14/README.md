## Authority and adaptation

Use current Live RPG decisions for mechanics. Use this archive for cultural detail, names, physical expression and future-world possibilities. Later explicit corrections in Grimnir Works supersede broad early prose about harmful stillness. Skylands, mature clan institutions and inter-people diplomacy belong to a developed period, not automatically to the game's newly awakened surface settlement. Assistant suggestions remain suggestions unless accepted or subsequently established.

The Worldbuilding Character Creation article is retained to document an incompatibility: its choose-race/choose-role avatar flow is a different game model and is not imported into this Live RPG's temporary inhabitation system.
